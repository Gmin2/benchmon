# benchmon brand kit

regenerate everything with `node src/kit.mjs` from `brand/`.

| file | size | use |
|---|---|---|
| x-profile-400.png, x-profile-800.png | 400 and 800 square | x / discord / telegram profile picture, safe inside the circle crop |
| x-header-1500x500.png, x-header-3000x1000.png | 3:1 | x header. cards sit right of the profile circle, logo and tagline on the right |
| og-image-1200x630.png | 1200x630 | link previews (already wired into the web app) |
| logo-square-1200.png | 1200 square | hackathon portal logo, app listings |
| logo-wordmark.svg | vector | the full logo, any size |
| logo-wordmark-transparent.png (2000w), -1000.png | transparent | logo over images or video |
| logo-wordmark-on-dark.png, -on-light.png | padded | slides, docs, press |
| logo-mon-mark.svg, logo-mon-mark-transparent.png | 1024 | the mon alone, stickers, avatars, favicon source |

colours: lime #b8ff3d, monad purple #7b62ff (depth #4b33c9), ink #101113. type: bowlby one sc for the wordmark, plus jakarta sans for text.
